# Sentiment Analysis Project

## Project Overview

This project is a simple **Sentiment Analysis** application that identifies whether a given text expresses a **Positive** or **Negative** sentiment.

Sentiment Analysis is a Natural Language Processing (NLP) technique used to understand the emotion or opinion present in text.

## Objective

The main objective of this project is to analyze user-entered text and classify it into:

* Positive Sentiment
* Negative Sentiment

## Example

**Positive Input:**

`I really enjoyed this product. It is amazing and works perfectly!`

**Output:**

Positive Sentiment 

**Negative Input:**

`I am very disappointed with this product. It is poor and does not work properly.`

**Output:**

Negative Sentiment

## Technologies Used

* Python
* Natural Language Processing (NLP)
* Sentiment Analysis
* Machine Learning / AI

## How It Works

1. User enters a sentence or review.
2. The system analyzes the text.
3. The sentiment of the text is identified.
4. The result is displayed as Positive or Negative.

## Applications

Sentiment Analysis can be used for:

* Product Review Analysis
* Customer Feedback Analysis
* Social Media Analysis
* Movie Review Analysis
* Brand Opinion Analysis

## Conclusion

This project demonstrates how AI and NLP can be used to understand human opinions from text. It provides a simple way to classify text based on its sentiment.
